FocusLock Native Android Architecture

Built following Clean Architecture + MVVM guidelines with Kotlin & Jetpack Compose.

PlatformAndroid Native (Kotlin 2.0)

Minimum SDKAPI 26 (Android 8.0 Oreo)
Target SDKAPI 35/36 (Android 15+)
Local DatabaseAndroidX Room with Transactions
Tracking EngineAccessibilityService + UsageStatsManager
Reboot RecoveryBootReceiver + AlarmManager / WorkManager
SecurityPBKDF2 Salted PIN + Android Keystore
Cloud Dependency100% Local-First (No external server)
Room Local Database Schema

5 core tables ensuring persistent state across device restarts:

  • protected_apps: packageName (PK), displayName, dailyLimitSeconds, enabled, category
  • usage_sessions: id (PK), packageName, startedAt, endedAt, durationSeconds, source
  • daily_usage: packageName + localDate (Unique), usedSeconds, quotaSeconds, isBlocked
  • focus_sessions: id, startedAt, plannedEndAt, actualEndAt, status
  • protection_events: id, eventType, timestamp, detailsCode
